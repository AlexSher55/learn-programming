# 2.6 — Classes и поля

Теория **с нуля**. Практика обязательна до контроля.

Связь: объекты / ссылки (`01-03`), типы (`02-02`).

---

## 1. Зачем классы

Типы вроде `int` и `String` — готовые. Свои сущности (пользователь, кнопка, заказ) описывают **классом**.

Класс — **чертёж**. Объект (instance) — **экземпляр** по этому чертежу в heap.

```dart
class User {
  String name;
  int age;

  User(this.name, this.age);
}

void main() {
  var u = User('Alex', 25); // создали объект
  print(u.name);            // Alex
}
```

- `class User { ... }` — определение чертежа.
- `User('Alex', 25)` — вызов конструктора, появляется объект.
- `u` хранит **ссылку** на этот объект.

## 2. Поля (fields)

Поля — слоты данных внутри объекта:

```dart
class Point {
  double x;
  double y;

  Point(this.x, this.y);
}
```

`this.x` — поле текущего объекта. В конструкторе `this.x` / `this.y` — короткий синтаксис: «положи аргумент в поле».

### `final` поля

```dart
class User {
  final String name;
  final int age;

  User(this.name, this.age);
}
```

После создания объекта `name` и `age` **нельзя переприсвоить**. Сам объект при этом может быть мутабельным, если есть другие не-`final` поля.

---

## 3. Методы

Метод — функция **внутри** класса, у неё есть доступ к полям через `this` (часто `this` можно не писать).

```dart
class Counter {
  int value = 0;

  void inc() {
    value++;
  }

  int getValue() => value;
}
```

```dart
var c = Counter();
c.inc();
print(c.getValue()); // 1
```

---

## 4. Несколько ссылок на один объект

```dart
var a = User('Alex', 25);
var b = a; // скопировали ссылку, не объект
b.age = 30; // если age не final
print(a.age); // 30 — тот же объект
```

Это тот же механизм, что в `01-03`.

---

## 5. Сравнение с JS

| JS | Dart |
|---|---|
| `class` / `constructor` | `class` / конструктор |
| `this.x = x` | поля + `this.x` в конструкторе |
| прототипы под капотом | своя объектная модель, для Core думай: класс → объекты |

В JS часто делают объекты-литералы `{}`. В Dart для «сущности с поведением» обычно **класс**.

---

## 6. Типичные ошибки

1. Забыть создать объект: обращаться к `User.name` как к статике без `static` (про static позже).
2. Путать класс и объект: «у класса age = 25» — нет, age у **экземпляра**.
3. Думать, что `var b = a` копирует поля — копируется ссылка.
