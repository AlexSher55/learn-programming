# Модуль 6 — Настройки, модели, приватность

## Два «Settings»

1. **Cursor Settings** — `Ctrl+Shift+J` (модели, Tab, privacy, AI).
2. Обычные **VS Code Settings** — редактор, формат, шрифты и т.д.

## Модели

- Переключение: пикер или `Ctrl+/`.
- Быстрые модели — рутина; сильные — сложный мультифайл / архитектура.
- Composer — семейство моделей Cursor (не путать со старым названием панели).

[Models & pricing](https://cursor.com/docs/models-and-pricing)

## Privacy Mode

Settings → General.  
На Teams часто принудительно. Смысл: код не идёт в обучение моделей (детали — в официальной доке).

[Privacy](https://cursor.com/help/security-and-privacy/privacy)

## Полезные шорткаты (Windows)

| Действие | Клавиши |
|----------|---------|
| Agent | `Ctrl+I` / `Ctrl+L` |
| Inline Edit | `Ctrl+K` |
| Меню режимов | `Ctrl+.` |
| Цикл режимов | `Shift+Tab` |
| Цикл моделей | `Ctrl+/` |
| Cursor Settings | `Ctrl+Shift+J` |

[Keyboard shortcuts](https://cursor.com/help/customization/keyboard-shortcuts)

## Context ring

В чате видно, чем заполнено окно контекста: система, tools, rules, skills, MCP, история.  
Если ответы «тупеют» на длинном треде — новый чат часто лучше, чем продолжать бесконечно.

## Упражнения

1. Открой Cursor Settings, найди Models, Privacy, Tab.
2. Переключи модель через `Ctrl+/` и сделай один и тот же простой запрос на двух моделях.
3. Посмотри context usage в длинном чате — что занимает место.

## Готово, когда

Знаешь, где менять модель/privacy и чем Cursor Settings отличаются от editor settings.
