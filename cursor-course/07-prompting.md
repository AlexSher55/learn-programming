# Модуль 7 — Как промптить агента

## Хороший запрос

- Цель / результат, а не «поиграйся с кодом»
- Ограничения: «не меняй публичный API», «только файлы в practice/»
- Критерий успеха: «добавь тест и прогони его»
- Контекст: `@` если знаешь файлы; скриншот для UI-багов

## Плохие привычки

- Один гигантский чат на всё подряд → новый чат на новую задачу
- Принимать весь дифф не глядя
- Чинить бесконечными «ещё поправь» вместо Plan / уточнения ТЗ
- Молчать про то, как запускать тесты (лучше в `AGENTS.md`)

## Тактика

1. Неясно → Plan Mode, поправить план, потом build  
2. Ясно и мелко → Agent или `Ctrl+K`  
3. Сломалось непонятно → Debug Mode  
4. Агент ушёл не туда → Checkpoint / откат, уточни ТЗ, заново

Документация: [Prompting](https://cursor.com/docs/agent/prompting)

## Упражнения

1. Одна задача дважды:  
   а) «улучши курс»  
   б) «В `cursor-course/00-start.md` добавь секцию FAQ из 3 вопросов. Не трогай другие файлы.»  
   Сравни диффы.
2. Приложи скриншот любой UI-проблемы (или нарисуй в Paint) и попроси агента описать, что он видит.
3. После неудачной попытки: Restore Checkpoint → переформулируй запрос с ограничениями.

## Готово, когда

Пишешь запросы с целью, границами и критерием успеха.
