# Модуль 8 — MCP

MCP (Model Context Protocol) подключает к агенту внешние инструменты: трекеры задач, дизайн, БД, доки и т.д.

## Зачем

Без MCP агент видит в основном файлы и терминал.  
С MCP — может вызывать инструменты сервисов (создать issue, прочитать Figma, и т.п.).

## Как подключается

- Marketplace one-click в Cursor
- Или конфиг: `.cursor/mcp.json` (проект) / `~/.cursor/mcp.json` (пользователь)
- Транспорты: stdio (локально), SSE, Streamable HTTP

Документация: [MCP](https://cursor.com/docs/mcp)

## Безопасность

- Только доверенные серверы
- Минимальные права у ключей/токенов
- Логи: Output → MCP Logs
- Approval для чувствительных действий

## Упражнения

1. Открой Customize / MCP и посмотри, что уже подключено.
2. Поставь один простой MCP из Marketplace (например, документацию или публичный tool) и вызови его по имени в чате.
3. (Опционально) Добавь project `.cursor/mcp.json` с переменными `${env:...}` / `${workspaceFolder}`.

## Готово, когда

Понимаешь, что MCP — это «руки агента во внешние системы», и где его включать/выключать.
