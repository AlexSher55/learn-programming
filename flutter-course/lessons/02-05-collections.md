# 2.5 — Collections: `List`, `Set`, `Map`

Теория **с нуля**. Практика обязательна до контроля.

Связь с прошлым: ссылка / mutation (`01-03`), `final` vs переприсваивание (`02-01`), циклы (`02-04`).

---

## 1. Зачем коллекции

Одна переменная — одно значение. Часто нужно **много** значений:
- список оценок;
- набор уникальных id;
- словарь «имя → возраст».

В Dart три базовые структуры:

| Тип | Идея | Пример |
|---|---|---|
| `List` | упорядоченная последовательность, есть индексы | `[10, 20, 30]` |
| `Set` | множество **уникальных** элементов, без дублей | `{'a', 'b'}` |
| `Map` | пары ключ → значение | `{'Alex': 25}` |

---

## 2. `List`

```dart
var scores = [10, 20, 30]; // List<int>
print(scores[0]);          // 10 — индекс с нуля
print(scores.length);      // 3
```

### Mutation

```dart
scores.add(40);     // добавить в конец
scores[1] = 99;     // заменить элемент
scores.remove(10);  // удалить значение 10 (первое вхождение)
```

Список — объект в heap. `var scores` / `final scores` хранят **ссылку**.  
`final scores = [1, 2]; scores.add(3);` — ок (mutation).  
`scores = [9, 9];` у `final` — ошибка (переприсваивание).

### Тип элементов

```dart
List<int> a = [1, 2];
List<String> b = ['a', 'b'];
// a.add('x'); // ошибка типа
```

Пустой типизированный список:

```dart
var empty = <int>[];
```

### `const` список

```dart
const frozen = [1, 2, 3];
// frozen.add(4); // ошибка: нельзя мутировать const
```

## 3. Перебор `List`

```dart
for (var s in scores) {
  print(s);
}

for (var i = 0; i < scores.length; i++) {
  print('$i: ${scores[i]}');
}
```

---

## 4. `Set`

```dart
var tags = <String>{'dart', 'flutter', 'dart'};
print(tags); // {dart, flutter} — дубль исчез
print(tags.contains('dart')); // true
tags.add('ui');
```

Порядок в `Set` не гарантируй как у `List` (для учёбы: «набор уникальных», не «массив с индексами»).

Индекса `[0]` у обычного `Set` нет.

---

## 5. `Map`

```dart
var ages = <String, int>{
  'Alex': 25,
  'Sam': 30,
};
print(ages['Alex']); // 25
print(ages['Bob']);  // null — ключа нет
```

Тип: `Map<K, V>` — ключ типа `K`, значение типа `V`.

```dart
ages['Alex'] = 26;   // обновить
ages['Bob'] = 40;    // добавить
ages.remove('Sam');  // удалить пару
print(ages.containsKey('Bob')); // true
```

Перебор:

```dart
for (var entry in ages.entries) {
  print('${entry.key} -> ${entry.value}');
}
```

---

## 6. Сравнение с JS

| JS | Dart |
|---|---|
| `Array` | `List` |
| `Set` | `Set` |
| object / `Map` | `Map` (и объекты классов — отдельно) |
| `arr[0]`, `obj.key` | `list[0]`, `map['key']` |

В JS «объект как словарь» привычен. В Dart для словаря бери **`Map`**, а не класс с полями (поля — в уроке про classes).

## 7. Типичные ошибки

1. Путать индекс и значение: `scores[10]` при длине 3 → runtime error.
2. Ждать, что `Set` сохранит дубли.
3. `ages['Bob']` вернул `null` — тип значения на чтении часто `V?`.
4. Думать, что `final list` нельзя менять содержимое — можно мутировать, нельзя переприсвоить имя.
