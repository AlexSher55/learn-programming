## 1. Зачем нужен control flow

Пока код идёт строго сверху вниз. Часто нужно:
- сделать что-то **только если** условие верно;
- выбрать один из нескольких вариантов;
- **повторить** действие несколько раз.

Это и есть control flow — управление потоком выполнения.

## 2. `if` / `else if` / `else`

```dart
void checkAge(int age) {
  if (age >= 18) {
    print('adult');
  } else if (age >= 13) {
    print('teen');
  } else {
    print('child');
  }
}
```

Как читать:
1. Проверяем первое условие.
2. Если `true` — выполняем блок, остальные ветки **пропускаем**.
3. Если `false` — идём к `else if`, потом к `else` (если есть).

Условие в скобках должно быть **`bool`** (или выражение, дающее `bool`). Не как в JS: `if (1)` или `if ('')` в Dart так не работает.

```dart
if (age) {} // ошибка: int — не bool
if (age != 0) {} // ок
```

### Условие как выражение

Часто нужен результат в переменную — тернарный оператор (как в JS):

```dart
var label = age >= 18 ? 'adult' : 'minor';
```

Обычный `if (...) { }` — это **оператор** (statement), его нельзя написать справа от `=` как в примере выше. Для выбора значения в выражении используй `? :` или `switch`-выражение (см. ниже).

## 3. `switch`

Когда ветвлений много по **одному** значению — удобнее `switch`, чем длинная цепочка `else if`.

```dart
String dayName(int day) {
  switch (day) {
    case 1:
      return 'Mon';
    case 2:
      return 'Tue';
    case 3:
      return 'Wed';
    default:
      return 'other';
  }
}
```

- `case` сравнивает значение с образцом.
- `default` — «если ничего не подошло».
- После `return` / `break` / `continue` / `throw` выход из ветки. В современном Dart часто используют `=>` или блок с `return`.

Сравнение с JS: идея та же, но в Dart типы строже, и есть **pattern matching** (позже углубим в Advanced). На уровне Core достаточно: «один switch — несколько case».

Пример с `=>`:

```dart
String mood(String weather) => switch (weather) {
  'sun' => 'happy',
  'rain' => 'sad',
  _ => 'ok', // _ = «всё остальное», как default
};
```

## 4. Цикл `for`

Повторить известное число раз или пройти по коллекции.

### Классический счётчик

```dart
for (var i = 0; i < 3; i++) {
  print(i); // 0, 1, 2
}
```

Части: старт → условие «пока true» → шаг после каждой итерации.

### `for-in` по коллекции

```dart
var names = ['Alex', 'Sam'];
for (var name in names) {
  print(name);
}
```

На каждой итерации `name` — следующий элемент. Не путай с JS `for...in` по ключам объекта — в Dart `for-in` идёт по **элементам** iterable.

---

## 5. `while` и `do-while`

```dart
var n = 3;
while (n > 0) {
  print(n);
  n--;
}
// 3, 2, 1
```

`while` проверяет условие **до** тела. Если сразу `false` — тело ни разу не выполнится.

```dart
var n = 0;
do {
  print(n);
  n++;
} while (n < 0);
// напечатает 0 один раз: тело сначала, проверка потом
```

---

## 6. `break` и `continue`

```dart
for (var i = 0; i < 10; i++) {
  if (i == 3) continue; // пропустить эту итерацию
  if (i == 7) break;    // выйти из цикла совсем
  print(i);
}
// 0, 1, 2, 4, 5, 6
```

- `continue` — «дальше к следующей итерации».
- `break` — «цикл закончен».

---

## 7. Сравнение с JS

| Идея | JS | Dart |
|---|---|---|
| условие | truthy/falsy | строго `bool` |
| `for` | похож | похож |
| `for...in` | ключи объекта | элементы iterable |
| `switch` | есть | есть + patterns |

---

## 8. Типичные ошибки

1. `if (count)` вместо `if (count > 0)`.
2. Бесконечный `while` — условие никогда не становится `false` (связь с call stack / зависанием программы).
3. Путать `break` и `continue`.
4. В `switch` забыть ветку «остальное» (`default` / `_`), когда она нужна.

---

## 9. Чеклист

- `if` / `else if` / `else`;
- условие только `bool`;
- `switch` / `case` / `default` / `_`;
- `for`, `for-in`, `while`, `do-while`;
- `break` vs `continue`.
