# Глоссарий Cursor

| Термин | Значение |
|--------|----------|
| **Agent** | AI, который ищет, правит, запускает tools |
| **Ask / Plan / Debug** | Режимы агента |
| **Tab** | AI-автодополнение |
| **Inline Edit** | `Ctrl+K` по выделению |
| **Checkpoint** | Локальный откат правок агента (не Git) |
| **@ mention** | Явный контекст в запросе |
| **Rules / `.mdc`** | Постоянные инструкции |
| **AGENTS.md** | Markdown-инструкции для агента в репо |
| **Skill** | Playbook `SKILL.md`, вызов через `/` |
| **Hook** | Скрипт на событиях цикла агента |
| **MCP** | Протокол внешних tools/данных |
| **Plugin** | Набор rules/skills/MCP/hooks/… |
| **Subagent** | Вложенный агент с отдельным контекстом |
| **Cloud Agent** | Агент на удалённой VM |
| **Automation** | Триггерный cloud-запуск |
| **Bugbot** | Авто-ревью PR |
| **Context window / ring** | Бюджет токенов + разбивка в UI |
| **Privacy Mode** | Режим приватности (см. docs) |
| **`.cursorignore`** | Исключения из AI-контекста |
| **Open VSX** | Реестр расширений Cursor |
| **Composer** | Семейство моделей Cursor (и устар. имя панели) |
