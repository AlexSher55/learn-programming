# Модуль 2 — Tab, Inline Edit, Agent

Три инструмента = три масштаба задачи.

## Tab (автодополнение)

- Предлагает код по мере набора (учитывает соседний код, недавние правки, иногда ошибки линтера).
- `Tab` — принять целиком  
- `Ctrl+→` — принять по словам  
- `Esc` — отклонить  
- Можно выключить/приостановить в статус-баре или Settings → Tab

Документация: [Tab](https://cursor.com/help/ai-features/tab)

## Inline Edit (`Ctrl+K`)

- Выдели код → опиши изменение → применить на месте.
- Вопрос по выделению: `Alt+Enter`.
- Важно: **User Rules не применяются** к Inline Edit.

Документация: [Inline edit](https://cursor.com/help/ai-features/inline-edit)

## Agent (боковая панель)

- Поиск по коду, правки многих файлов, терминал, браузер, уточняющие вопросы.
- Есть **checkpoints** — откат файлов к состоянию до правок агента.
- Старые гайды могут говорить «Composer» — сейчас это в основном **Agent** (Composer также имя модели Cursor).

Документация: [Agent overview](https://cursor.com/docs/agent/overview)

## Правило выбора

| Задача | Инструмент |
|--------|------------|
| Дописать 2–10 строк тут же | Tab |
| Переписать одну функцию / блок | `Ctrl+K` |
| Фича, рефакторинг, баг, «найди где…» | Agent |

## Упражнения

1. Создай файл `practice/hello.js` вручную. Начни писать функцию и доведи её через **Tab**.
2. Выдели функцию → `Ctrl+K` → «перепиши на async/await и добавь обработку ошибок».
3. Ту же идею попроси через **Agent**, но с тестом в отдельном файле. Сравни: где больше контроля, где больше скорости.

## Готово, когда

Без подсказки выбираешь Tab / K / Agent под размер задачи.
