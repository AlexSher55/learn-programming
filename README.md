## Как учиться

1. Смотри прогресс: [cursor-course/PROGRESS.md](cursor-course/PROGRESS.md).
2. Открой текущий модуль по таблице выше.
3. Сделай упражнения (в проекте или в чате с агентом).
4. Напиши «готово» / «следующий» — агент обновит `PROGRESS.md`.
5. Если работаешь с двух ПК: `git commit` + `git push` после занятия, на другом — `git pull`.

На любом устройстве достаточно сказать агенту: **«Прочитай PROGRESS.md и продолжим»**.
