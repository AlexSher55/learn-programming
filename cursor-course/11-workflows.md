# Модуль 11 — Рабочие сценарии

Шпаргалка «что включить»:

| Задача | Подход |
|--------|--------|
| Новый репозиторий, ориентация | Ask → потом мелкий Agent-фикс |
| Мелкая правка | Tab или `Ctrl+K` |
| Фича на много файлов | Plan → approve → Agent → тесты → review |
| Рефакторинг | Plan/Agent + checkpoints; крупное — `/split-to-prs` |
| Сложный баг | Debug Mode |
| Ревью ветки | `@Branch` + `/review` / Bugbot |
| UI | скриншоты, browser tool, Design Mode |
| Долго / параллельно | Cloud Agent, Automations |

## Финальное упражнение курса

Собери end-to-end в этом репо:

1. **Ask**: опиши, чего не хватает курсу.
2. **Plan**: план улучшения (1–2 файла максимум).
3. **Agent**: реализуй.
4. Прогони глазами дифф; при желании попроси агента написать summary изменений.
5. (Опционально) Cloud / PR, если готов.
