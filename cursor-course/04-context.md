# Модуль 4 — Контекст: @, индекс, ignore

Агент хорошо работает, когда видит нужное. Есть два пути:

1. Сам найдёт через поиск по репозиторию.
2. Ты явно приложишь контекст через `@`.

## @ mentions

Через `@` можно прикрепить: файлы, папки, терминалы, прошлые чаты, git-диффы (working tree / branch), браузер.

Правило: если точно знаешь файл — `@` его. Если не знаешь — просто опиши задачу.

Документация: [Context](https://cursor.com/help/customization/context)

## Индексация и ignore

- Cursor индексирует кодовую базу для поиска агентом.
- Учитывается `.gitignore`.
- Дополнительно: `.cursorignore` — скрыть от AI то, что не должно попадать в контекст (секреты, огромные артефакты).

Важно: ignore режет file-tools агента; терминал/MCP теоретически всё ещё могут достучаться — секреты держи вне репо.

Документация: [Ignore files](https://cursor.com/help/customization/ignore-files)

## Упражнения

1. В Agent: `@cursor-course/02-core-tools.md` и спроси «сожми это до 5 пунктов для шпаргалки».
2. Создай `.cursorignore` и добавь туда, например, `tmp/` или `*.secret` (даже если файлов ещё нет).
3. Сравни ответ агента с `@файлом` и без — заметь разницу в точности ссылок.

## Готово, когда

Понимаешь, когда @ нужен, а когда достаточно обычного запроса + поиска.
