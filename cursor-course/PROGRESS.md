- Синхронизацию папок `%APPDATA%\Cursor` решили не использовать.
- MCP YouTrack/Figma на учебный трек не обязательны.

## Как продолжить на другом ПК

1. `git pull`
2. Открыть эту папку в Cursor
3. В Agent: `Прочитай PROGRESS.md и продолжим учёбу с текущего модуля`
4. После занятия: попросить агента обновить PROGRESS.md → `git add` / `commit` / `push`
