# Корректность вёрстки на различных разрешениях экранов (768, 1024, 1240, 1960)

Проверены ключевые страницы: главная, о нас, проекты, новости, навигатор, контакты, регистрация, правила, cookies, пространство, политика, предприятия, ЛК (профиль, записи, лояльность, квизы, конкурс).

## Ширина 768px

### На 768px контент сжимается в узкую колонку, справа большая пустота

На главной, в ЛК и на ряде внутренних страниц основной контейнер занимает примерно половину окна (мобильный/узкий layout), справа остаётся пустая зона ~300–400px — вёрстка «едет», страница не использует ширину.

**Где:** `/`, `/personal/`, `/personal/loyalty/`, `/personal/quiz/`, `/projects/` и др.  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

### На 768px шапка не на всю ширину окна

Фиксированная/мобильная шапка существенно уже viewport (порядка ~379px при 768) — визуально «обрывок» слева, остальное пусто.

**Где:** почти все страницы.  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

### На 768px левое меню ЛК пропадает — ломает навигацию кабинета

Сайдбар с разделами ЛК не виден; остаются только иконки в шапке. Навигация по кабинету ломается.

**Где:** `/personal/*`  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

### На 768px карточки слайдера предприятий выезжают за край экрана

Часть слайдов/заголовков/кнопок «Узнать подробнее» уходит за правую границу окна.

**Где:** `/`  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

### На 768px неровная сетка карточек на «Проекты»

В одном визуальном ряду высоты карточек сильно различаются (сетка «пляшет»).

**Где:** `/projects/`  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

### На 768px в лояльности текст не помещается в плашки баллов

Подписи у плашек переносятся впритык к краям блока, визуально ломают карточку баланса.

**Где:** `/personal/loyalty/`  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

### На 768px вкладка «Мой баланс» смещена относительно рамки контента

Активная вкладка не совпадает с границей контейнера — смещение элементов.

**Где:** `/personal/loyalty/`  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

## Ширина 1024px

### На 1024px страница ломается горизонтальным скроллом

`scrollWidth` больше ширины окна (например ~1153 > 1024) — страница едет вбок.

**Где:** особенно `/personal/`, также проявляется на других страницах с широкой шапкой/контентом.  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

### На 1024px кнопка «ПРОФИЛЬ» выезжает за край / обрезается

Кнопка уходит за правую границу окна («ПРОФИ…») — элемент не помещается в шапку.

**Где:** шапка на всех страницах.  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

### На 1024px шапка уже окна

Ширина `.header_fixed` меньше viewport (например ~992 при 1024) — зазор, шапка «прыгает» при скролле.

**Где:** все страницы.  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

### На 1024px кнопки «Редактировать» и «Настройки» не помещаются и выезжают за границы карточки

Текст обрезан («Редактиров…» / «…астройки»), кнопки наезжают друг на друга и выходят за левую/внутреннюю границу блока профиля — ломают карточку.

**Где:** `/personal/`  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

### На 1024px контент ЛК обрезается справа, страница визуально «разрезана»

Правая часть layout обрезана/уходит за край; ломает страницу в целом.

**Где:** `/personal/`  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

### На 1024px на главной огромная пустая зона — вёрстка разъезжается

Блоки смещаются, по центру/сбоку лишняя пустота.

**Где:** `/`  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

### На 1024px текст не помещается в кнопки («СМОТРЕТЬ ВСЕ» и др.)

Перенос/наезд текста на рамку кнопки.

**Где:** `/` и блоки со ссылками «смотреть все».  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

## Ширина 1240px

**Где:** `/personal/`

### На 1240px блок ЛК прижат влево, справа широкая пустота

Меню + карточка не заполняют ширину; появляется внутренний скролл контейнера — вёрстка «едет».

**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

### На 1240px шапка и контент не выровнены по ширине окна

**Где:** страницы ЛК и часть публичных.  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

### На 1240px неровная сетка карточек (проекты / новости / навигатор)

В одном ряду разная высота карточек — сетка неровная, нижний край и кнопки «Подробнее» не на одной линии.

## Ширина 1960px (широкий монитор)

### На 1960px шапка не на всю ширину — зазор справа

`.header_fixed` заметно уже окна (порядка 1380px при ~1600–1960), справа пустота; при скролле шапка «прыгает».

**Где:** все страницы.  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

### На 1960px контент и шапка не растягиваются — ломает ощущение цельной страницы

Большие поля по бокам, layout «застрял» на меньшей ширине; на части страниц возможен горизонтальный скролл при несовпадении ширин контейнеров.

**Где:** `/`, `/news/`, `/personal/*` и др.  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

### На широких экранах слайдер/карточки могут выезжать за границы родителя

Элементы slick/карточек выходят за `slick-list` / контейнер.

**Где:** `/`  
**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

# Десктопные устройства (Windows, macOS)

На Windows и macOS (macOS — через эмулятор) воспроизводятся те же проблемы ширин **1024 / 1240 / 1960**: обрезка «ПРОФИЛЬ», горизонтальный скролл, шапка не на всю ширину, ломаный ЛК, неровные сетки.

**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

# Мобильные устройства (iOS, Android)

На реальных iOS/Android — те же баги узких ширин и mobile UX: узкая колонка + пустота, пропажа меню ЛК, наслоение меню, cookie, сжатый конкурс, кривой поиск/фильтры.

**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

# Планшеты

На планшетных и промежуточных ширинах (**~768–1024**) вёрстка ломается сильнее всего: горизонтальный скролл, обрезанная шапка/кнопки, ЛК без нормального меню или с выездом кнопок за границы карточки, неровные сетки проектов/новостей/навигатора.

**повторяется в:** Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge

---

# Браузеры

Проверка в актуальных: Google Chrome, Safari, Яндекс.Браузер, Mozilla Firefox, Opera, Microsoft Edge.

По перечисленным ошибкам вёрстки и клиентского UI критичных отличий «только в одном браузере» не выявлено — баги **повторяются во всех** указанных браузерах (см. строку под каждым пунктом).
