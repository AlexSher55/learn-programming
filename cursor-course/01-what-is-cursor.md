# Модуль 1 — Что такое Cursor

## Суть

Cursor = VS Code + AI-агент поверх редактора.

| Унаследовано от VS Code | Только Cursor |
|-------------------------|---------------|
| Файлы, терминал, Git UI, Command Palette | Agent, Tab, Inline Edit |
| Темы, многие настройки, модель расширений | Rules, Skills, MCP, Cloud Agents |
| Горячие клавиши редактора | Доп. AI-шорткаты |

Расширения ставятся из **Open VSX** (не полный Visual Studio Marketplace) — большинство популярных есть, но не все.

## Ключевые идеи

1. **Агент** — не «чат ради чата», а исполнитель: читает код, правит файлы, запускает команды.
2. **Дифф нужно читать** — принимать изменения осознанно.
3. **Checkpoint ≠ Git** — checkpoint откатывает правки агента в сессии; Git — настоящая история проекта.

## Упражнения

1. Открой Agent (`Ctrl+I`) и напиши:  
   `Объясни структуру этой папки. Что здесь учебное, с чего начать читать?`
2. Попроси три безопасных улучшения репозитория. Выбери одно, посмотри дифф, прими или отклони.
3. Если есть опыт VS Code — импортируй настройки и отметь, что перенеслось, а что Cursor-специфичное.
