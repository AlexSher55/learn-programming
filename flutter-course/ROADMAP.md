# Roadmap — Strong Flutter Developer

## 1. CS foundation
CPU, RAM, memory model, stack/heap/call stack, references, mutation, GC, recursion basics.

## 2. Dart Core
Types, inference, `var/final/const`, null safety, functions, collections, control flow, classes, constructors, inheritance/composition, enums, extensions, generics, exceptions.

## 3. Algorithms I
Big O, linear/binary search, sorting basics, recursion, two pointers, sliding window, frequency maps.

## 4. Data Structures
Array/List, String, Stack, Queue, Set, Map/HashMap, Linked List, Tree, Heap, Graph.

## 5. Dart Advanced
Future, async/await, microtasks/event queue, Stream, isolates, records/patterns, mixins, sealed types, advanced generics.

## 6. Flutter Core
Widget tree, Element tree, RenderObject tree, BuildContext, constraints/layout, lifecycle, keys, navigation.

## 7. UI Engineering
Responsive/adaptive UI, forms, validation, animations, accessibility, localization, design systems.

## 8. State Management
Local state first, then principles and comparison of common approaches; immutable state and predictable updates.

## 9. Data Layer
REST, serialization, repositories/services, authentication, persistence, caching, pagination, offline-first concepts.

## 10. Architecture
Separation of concerns, feature-first structure, DI, boundaries, domain layer where justified, error modeling.

## 11. Quality
Unit/widget/integration tests, mocks/fakes, debugging, logging, code review, refactoring.

## 12. Performance
Rebuilds, rendering, lists, image/memory usage, profiling, DevTools, CPU-heavy work and isolates.

## 13. Platform
Android/iOS lifecycle, permissions, deep links, notifications, platform channels/native integrations.

## 14. Production
Environments/flavors, secrets, analytics/crash reporting, CI/CD, signing, stores and release process.

## 15. Capstone
Production-like app from incomplete business requirements to architecture, implementation, tests, profiling and release plan.
