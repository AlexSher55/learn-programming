# Модуль 3 — Режимы Agent / Ask / Plan / Debug

Переключение: `Shift+Tab` или меню режимов (`Ctrl+.`).  
У каждого режима **свой контекст** — смена режима = новое окно контекста.

| Режим | Для чего | Правит файлы? |
|-------|----------|---------------|
| **Agent** | фичи, рефакторинг, правки | Да |
| **Ask** | разобраться, архитектура, «как работает» | Нет (read-only) |
| **Plan** | большая/неясная задача | После утверждения плана |
| **Debug** | баги, где нужны runtime-улики | Да, точечно |

Документация: [Plan Mode](https://cursor.com/docs/agent/plan-mode) · [Debug Mode](https://cursor.com/docs/agent/debug-mode)

## Когда какой

- Непонятно «что вообще делать» → **Plan**
- «Объясни, не трогай» → **Ask**
- Понятная задача на реализацию → **Agent**
- Баг плавает / нужен лог при воспроизведении → **Debug**

Rules действуют во всех четырёх режимах. На **Tab** rules не влияют.

## Упражнения

1. **Ask**: «Как устроен этот учебный репозиторий? Какие файлы за что отвечают?» — убедись, что файлы не менялись.
2. **Plan**: «Добавь в курс чеклист прогресса студента» — отредактируй план руками, потом согласись на build (или отмени).
3. **Debug** (позже, когда будет код с багом): воспроизведи шаги, которые попросит режим.

## Готово, когда

Переключаешь режим осознанно, а не сидишь всегда только в Agent.
