# Инструкции для агента (этот учебный репозиторий)

Это учебный полигон, не продакшен-проект.

## Цель

Помогать пользователю изучать Cursor (и позже другие темы) через короткие объяснения и практические упражнения.

## Прогресс между устройствами

- Источник правды: `cursor-course/PROGRESS.md`.
- В начале сессии по учёбе **сначала прочитай PROGRESS.md** (и при необходимости файл текущего модуля).
- Не проси пользователя заново пересказывать историю курса.
- Когда модуль/упражнение завершены или пользователь говорит «готово» / «следующий» — **обнови PROGRESS.md**: чеклист, «Сейчас», упражнения, краткие заметки.
- Напоминай закоммитить и запушить прогресс, если работа идёт с разных ПК. Коммит делай только по явной просьбе.

## Как отвечать

- Пиши по-русски, если пользователь пишет по-русски.
- Объясняй коротко: сначала суть, потом детали по запросу.
- После теории сразу давай 1–3 упражнения, которые можно сделать прямо сейчас.
- Не усложняй структуру репозитория без нужды.
- Материалы курса лежат в `cursor-course/`.

## Чего не делать

- Не превращай учебные файлы в огромные энциклопедии.
- Не коммить изменения, пока пользователь явно не попросит.
