# Модуль 0 — Старт

## Зачем этот курс

Cursor — это редактор кода с встроенным AI-агентом (форк VS Code).  
Цель курса — не «знать названия кнопок», а уверенно:

- выбирать правильный инструмент под задачу;
- давать агенту хороший контекст;
- настраивать правила и интеграции;
- проверять результат, а не слепо принимать диффы.

- [ ] Cursor установлен

## Три поверхности AI (запомни сразу)

| Инструмент | Когда | Горячая клавиша (Windows) |
|------------|-------|---------------------------|
| **Tab** | подсказки по мере набора | `Tab` принять |
| **Inline Edit** | правка выделенного куска | `Ctrl+K` |
| **Agent** | задача на несколько файлов / поиск / терминал | `Ctrl+I` или `Ctrl+L` |

## Как работать с этим проектом

В чате можно писать:

- `объясни модуль 2` — разбор темы
- `дай упражнение` — практика
- `проверь, правильно ли я сделал` — разбор результата
- `следующий модуль` — переход дальше
