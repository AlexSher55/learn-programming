# Practice — Dart / Flutter

Сюда складываются runnable-упражнения курса.

## Как запускать

Из корня `flutter-course`:

```bash
dart run practice/02-03/task_01.dart
```

Или открой файл и запусти из IDE.

## Порядок

1. Прочитай теорию урока в `lessons/`.
2. Открой папку `practice/XX-YY/`.
3. В каждом `task_*.dart` есть `TODO` и комментарий «ожидаемый результат».
4. Реши сам (на 🔴 — без генерации решения AI).
5. Запусти, проверь вывод.
6. Напиши агенту: «проверь практику» (можно указать пути к файлам).

## Папки

| Папка | Урок | Обязательность |
|---|---|---|
| `02-01/` | var / final / const | по желанию (закрепление) |
| `02-02/` | типы | по желанию (закрепление) |
| `02-03/` | функции | обязательна до контроля |
| `02-04/` … `02-12/` | остальной Dart Core | обязательна до контроля |

Решения пиши прямо в `task_*.dart`. Отдельные «эталонные» файлы не нужны — агент проверяет твой код.
